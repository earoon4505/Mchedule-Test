# 🍁 메케줄(MapleSchedule) v1.2.2 릴리즈 노트

**적용 대상**: Windows 데스크톱 앱 (Electron) 및 공식 웹 애플리케이션

## 📌 주요 업데이트 요약

### 1. 📂 '전체' 탭 섹션 펼침/접힘 상태 영구 기억
* **사용자 맞춤 섹션 상태 유지 (`mapleschedule_section_collapsed_v1`)**:
  - `'전체'` 탭 내 6개 섹션(`일일 컨텐츠`, `일일 보스`, `주간 컨텐츠`, `주간 보스`, `검은 마법사`, `커스텀`)의 펼침/접힘 상태를 `localStorage`에 자동 저장합니다.
  - 다른 캐릭터로 전환하거나 개별 탭에 다녀온 뒤, 또는 앱/브라우저를 다시 실행해도 사용자가 마지막으로 설정해 둔 펼침/접힘 상태가 그대로 유지됩니다.
  - 개별 컨텐츠 탭(`일일`, `주간`, `보스`, `커스텀`)으로 이동할 때는 항상 목록이 펼쳐진 상태로 표시되어 즉시 확인이 가능합니다.

### 2. 🍄 라이트 모드 '주황버섯 살구 크림' 테마 개편
* **눈의 피로를 줄인 따뜻한 살구 크림 톤 적용**:
  - 기존 순백색 중심의 밝은 라이트 모드 배경을 메이플스토리 마스코트 주황버섯의 따뜻한 크림빛에서 착안한 **은은한 살구 크림 톤**으로 전면 개편했습니다.
  - **메인 배경**: `#FBF3EB` / **헤더·양쪽 사이드바·모바일 내비게이션 바**: `#FCF6EF` / **미완료 카드·탭 바**: `#FFFDFB` / **테두리**: `#EEDFD0`, `#EBDACA`
* **내부 회색(`slate`) UI 요소 웜 톤 통합 정리**:
  - 카드와 사이드바, 진행 현황 패널 내부에 남아 있던 차가운 회색(`slate`) 배지, 보조 버튼, 체크박스 테두리, 게이지 트랙을 한 톤 밝고 산뜻한 크림/베이지 계열(`#F8EDE1`, `#F5E8DA`, `#F4E6D8`, `#DEC8B3`)로 통일하여 회색빛 이질감과 답답함을 제거했습니다.

### 3. 🌙 다크 모드 명도 계층 개편 및 호버·시인성 버그 수정
* **4단 딥 차콜 명도 계층 적용**:
  - 기존 사이드바·헤더와 카드가 같은 명도(`slate-900`)로 겹치던 구조를 개선해 **메인 배경(`#0B0E14`) → 헤더·사이드바·모바일 네비게이션(`#111620`) → 미완료·PiP 카드(`#171E2C`) → 보조 버튼·뱃지·게이지 트랙(`#20293B`)**의 입체적 명도 계층으로 개편했습니다.
* **다크 모드 호버 번쩍임 및 가독성 개선**:
  - 캐릭터 카드 및 웹 PiP 하단 현황 뱃지(`일보`, `주보`, `일일`, `주간`) 호버 시 `dark:hover:bg-...` 누락으로 밝은 파스텔색이 튀던 문제를 해결했습니다.
  - 6개 스케줄 섹션 접기/펼치기 버튼(`slate-750`) 및 설정 모달 백업/복원 버튼(`slate-850`)의 미적용 호버 클래스를 유효한 다크 톤(`#20293B` / `#2A354C`)으로 수정했습니다.
  - 미등록 뱃지(`검마 -`, `커스텀 -`) 및 PiP 다계정 비활성 점의 어두운 배경 위 시인성을 개선했습니다.

### 4. 🪟 PiP 및 설정·약관·가이드 전체 화면 테마 일체화
* **PiP(Picture-in-Picture) 라이트·다크 카드 스타일 일체화**:
  - 데스크톱 독립 PiP 창(`StandalonePiPView`) 및 웹 인앱 PiP(`PiPOverlay`)의 캐릭터 카드(일반 상세 모드·프로필 사진 전용 모드), 계정 공통 컨텐츠 버튼, 레벨·미등록 뱃지, 다계정 인디케이터 점 색상을 메인 화면의 라이트/다크 카드 톤과 동일하게 맞췄습니다.
  - Electron PiP 창의 투명 배경 처리는 100% 보존됩니다.
* **설정, 이용약관, 개인정보처리방침, 가이드 모달 및 독립 페이지 컬러 통일**:
  - 설정 모달(`SettingsModal`), 운영 정책 및 법적 고지 모달·페이지(`LegalModal`, `/terms`, `/privacy`), 이용 가이드 모달·페이지(`GuideModal`, `/guide`) 전체에 라이트 모드(살구 크림)와 다크 모드(4단 딥 차콜) 컬러 시스템을 동일하게 적용했습니다.
  - 독립 웹페이지(`/guide`, `/terms`, `/privacy`) 직접 접속 및 새로고침 시에도 저장된 다크 모드 설정이 즉시 반영되도록 동기화 처리를 추가했습니다.
